# Rust Learning

This repository showcases activities from the “[Aprende Rust](https://aprenderust.dev/)” course created by content creator MiduDev [https://www.youtube.com/@MiduDev](https://www.youtube.com/@MiduDev). Here, I'll upload what I learn from MiduDev's course and some simple projects to demonstrate what I've learned.

### Notes
- Most of the projects/activities posted here are created by me without the use of artificial intelligence
- AI will play a minimal role in this repository. For example, it will help me identify my problems or errors; however, the purpose of learning is to make mistakes. It will also help me find cleaner alternatives for the code, but it won't write the code from scratch.
- As mentioned above, the purpose of this repository is to share what I learned throughout the course.
